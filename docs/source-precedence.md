# Source precedence

Only ownership-authoritative sources enter ownership replay. Resolution sorts first by effective/observed time. At the same time, explicit overrides win, then authority: user correction, confirmed transaction/waiver result, ESPN current evidence, current roster screenshot, other snapshot, draft. Recorded time and immutable ID break exact ties deterministically. Older evidence remains queryable. News, analysis, rankings, projections, and reports have `NON_OWNERSHIP` authority and never create ownership events.
